# Store screenshots

Add Chrome Web Store screenshots to this directory.

Use a normal Chrome session with the unpacked release package installed. Headless Chrome blocks the extension page in this environment.

Capture each image at `1280x800` pixels. Do not include API keys, tokens, private URLs, or personal account data.

Recommended screenshots:

1. The top of the options page with the main actions and duplicate settings.
2. The AI provider section with the cloud data disclosure visible.
3. A browser window with example tabs organized into named groups.
