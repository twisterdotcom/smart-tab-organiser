Smart Tab Organiser

Settings & Configuration

How to Use

Click the extension icon to deduplicate tabs and tidy your pinned tabs (unpin tabs not in your list, pin matching ones, reorder to match your list). If no tabs are pinned yet, the extension will pin tabs from your list (opening new tabs for any URL not already open). Duplicate detection uses your settings (e.g. keep highest anchor). The icon badge shows how many duplicate tabs are open.

Three ways to run: (1) Click the extension icon to deduplicate and tidy pinned tabs. (2) Right-click → "Deduplicate and organize tabs with AI" to dedupe and reorganize with AI. (3) Right-click → "Deduplicate and tidy pinned tabs" does the same as the icon click.

AI Tab Organization: Use "Organize tabs with AI" from the context menu, keyboard shortcut (⌘+Shift+O / Ctrl+Shift+O), or "Organize Tabs" in the popup. Configure a provider below — cloud (your own API key) or fully on-device.

Actions

Duplicate Detection Settings

Configure how the extension identifies duplicate tabs.

When enabled, URLs with different query strings are treated as duplicates.
Example: example.com/?a=1 and example.com/?b=2 are considered duplicates.

When enabled, URLs are compared without their hash/anchor, but the hash is still used to determine which tab to keep (highest anchor number).
Example: example.com/#comment-123 and example.com/#comment-456 are duplicates, but the one with #comment-456 is kept.

When enabled, remaining tabs will be automatically reloaded after closing duplicates.

Pinned tabs

Define which URLs should be Chrome-pinned (compact favicon tabs on the left of the tab bar). When you run "Deduplicate and tidy pinned tabs" or organize with AI, any pinned tab not in this list will be unpinned, and matching unpinned tabs will be pinned and ordered. If no tabs are pinned yet, the extension will pin tabs from this list (opening new tabs for any URL not already open).

Exact match (no prefix): only that exact URL stays pinned (after normalizing query/hash per your duplicate settings).
Prefix match: start a line with * so any tab whose URL starts with the rest of the line stays pinned (e.g. *https://mail.google.com/mail/u/0 keeps inbox, drafts, etc.; *https://chatgpt.com/ keeps any ChatGPT page; *https://app.slack.com/client/E047TPA624F keeps that workspace and any channel).
Soft (only when already open): start with ~ so the tab is only pinned when it already exists in the window; the extension never opens it. Use ~*https://... for soft prefix or ~https://... for soft exact. Example: ~*https://app.slack.com/client/E047TPA624F keeps Slack pinned only in windows where you have Slack open — it won’t be recreated in new windows. Leave empty to keep all currently pinned tabs as-is when tidying.

Colour for the BOOKMARKS tab group. Applied whenever you run dedupe/tidy so the group keeps this colour.

GitHub PR tab group

When enabled, the extension maintains a tab group named PRs with one tab per open pull request (authored by you or awaiting your review). Only the extension adds or removes tabs in this group. Your token is stored locally and used only to call the GitHub API.

Used only to fetch your open PRs and PRs awaiting your review. Requires at least read:user; for private repos use repo.
Create a token: github.com/settings/tokens

When enabled, a tab group named PRs is created or updated with one tab per open PR. When you run dedupe/organize, the extension refreshes this group first and treats the tab in the PR group as the main copy when closing duplicates elsewhere (split-view tabs are still never closed).

Manually refresh the PRs tab group now. It also refreshes automatically when you run dedupe/organize.

AI Tab Organization

Pick a provider, configure it in its card below, and choose what happens if it fails. Cloud providers need an API key (stored locally, never shared). On-device providers need no key and send nothing over the network.

Chrome built-in AI Primary

Gemini Nano, running inside Chrome itself. Chrome downloads the model (a few GB) once; after that it works fully offline.

Requirements & notes

Chrome 138+ on desktop, about 22 GB of free disk space, and either 4 GB+ of VRAM or 16 GB+ of RAM. Gemini Nano is much smaller than cloud models, so grouping is coarser; tabs are organized in batches of 20 to fit its context window.

Local model Primary

Any local server with an OpenAI-compatible API: Ollama, LM Studio, llama.cpp, vLLM.

Ollama / LM Studio setup

Ollama must be started with extension requests allowed, otherwise it rejects them: OLLAMA_ORIGINS="chrome-extension://*" ollama serve

In LM Studio, enable CORS in the local server settings; llama.cpp's server allows this by default. Enter the model name exactly as your server reports it — "Test connection" lists what it can see.

If the provider fails

If your preferred provider fails (invalid key, rate limit, outage, bad response), automatically try the other configured providers in order. An on-device primary only falls back to the other on-device provider, so tab data stays on this machine.

Also allow cloud providers with a saved API key as a last resort when the on-device options fail.
When this happens, tab titles and URLs are sent to that cloud provider. Leave off to guarantee tab data never leaves this machine.

Organisation behaviour

Provide custom instructions for how tabs should be organized (e.g., "group by domain", "group by topic", "prioritize work-related tabs").
These instructions will be used when organizing tabs from the options page.

When enabled, tabs that are already in groups will be skipped during organization.
When disabled, all tabs will be reorganized into new groups.
Pinned tabs and groups named "BOOKMARKS" and "PRs" are always preserved, regardless of this setting.

When set, only groups that have more than N tabs are preserved. Groups with N tabs or fewer are ungrouped and sent through AI organization again.
AI will also never create a new group with N or fewer tabs; such tabs go into Misc.
Example: with 2, groups with 3+ tabs are preserved; groups with 1–2 tabs are re-organized, and new groups have at least 3 tabs.

This feature may not work well if the number is higher than 3.

When enabled, the AI will intelligently merge ungrouped tabs into existing groups where appropriate.
This works best when "Preserve existing groups" is also enabled. The AI will analyze existing groups and merge new tabs into them.
Pinned tabs and the "BOOKMARKS" group are always preserved; these options apply to other groups only.

When enabled, after organization, tabs inside each group are ordered alphabetically by page title (A–Z).
BOOKMARKS and PRs groups are not reordered.

When enabled, clicking the extension icon will deduplicate tabs AND organize them using AI.
When disabled, the extension icon will only deduplicate tabs (default behavior).

Settings are automatically saved.
