Settings & Configuration

Actions

Duplicate Detection Settings

Configure how the extension identifies duplicate tabs.

When enabled, URLs with different query strings are treated as duplicates.
Example: example.com/?a=1 and example.com/?b=2 are considered duplicates.

When enabled, URLs are compared without their hash/anchor, but the hash is still used to determine which tab to keep (highest anchor number).
Example: example.com/#comment-123 and example.com/#comment-456 are duplicates, but the one with #comment-456 is kept.

When enabled, remaining tabs will be automatically reloaded after closing duplicates.

AI Tab Organization Settings

Configure API keys for AI-powered tab organization. Your API keys are stored locally and never shared.

Enter your OpenAI API key to use GPT models for tab organization. Leave empty to disable.
Get your key: platform.openai.com/api-keys

Enter your Anthropic Claude API key to use Claude models for tab organization. Leave empty to disable.
Get your key: console.anthropic.com/settings/keys

Choose which AI provider to use for tab organization. The selected provider must have a valid API key configured.

Choose which OpenAI model to use for tab organization.

Choose which Claude model to use for tab organization.

Provide custom instructions for how tabs should be organized (e.g., "group by domain", "group by topic", "prioritize work-related tabs").
These instructions will be used when organizing tabs from the options page.

When enabled, tabs that are already in groups will be skipped during organization.
When disabled, all tabs will be reorganized into new groups.

When enabled, the AI will intelligently merge ungrouped tabs into existing groups where appropriate.
This works best when "Preserve existing groups" is also enabled. The AI will analyze existing groups and merge new tabs into them.

When enabled, clicking the extension icon will deduplicate tabs AND organize them using AI.
When disabled, the extension icon will only deduplicate tabs (default behavior).

How to Use

Click the extension icon in your Chrome toolbar to instantly close duplicate tabs.

The extension will:

  • Detect duplicate tabs based on your settings
  • Keep the tab with the highest anchor number (e.g., latest GitHub comment)
  • Close all other duplicates

The extension icon badge shows how many duplicate tabs are currently open.

AI Tab Organization: Use the "Organize Tabs" button in the popup to automatically group your tabs using AI. Configure your API keys above to enable this feature.

Settings are automatically saved.
